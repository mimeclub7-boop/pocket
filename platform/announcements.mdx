The Announcements page publishes platform updates: maintenance windows, testnet resets, new markets, and incident postmortems. Check it before trading if you notice unusual behavior.

## How to access

Top navigation → **Announcement**

## Page structure

| View | Content |
| --- | --- |
| List | Title, date, tag (e.g. Maintenance, Release, Incident) |
| Detail | Full markdown body, optional links |

## Tags

## Notifications

V2 may surface an unread badge on the Announcement nav item when new posts ship. There is no email subscription in testnet V2.

## Operations

Content is managed internally (CMS or markdown in repo). For urgent issues, also check status via team channels.
