Pocket is non-custodial. You connect a wallet you control; Pocket never holds your private keys.

## Supported wallets

| Wallet | Connection method |
|---|---|
| MetaMask | Browser extension / in-app browser |
| WalletConnect | QR code or deep link |
| OKX Wallet | Extension or mobile |
| Coinbase Wallet | Extension or mobile |

## Connect flow

1. Click **Connect Wallet** in the top bar or on the trade panel
2. Select your wallet provider
3. Approve the connection request in your wallet
4. Your address appears in the top bar when connected

## Enable Trading

Connecting a wallet alone does not authorize trading. Click **Enable Trading** to:

1. Claim testnet tokens (if not already claimed)
2. Sign a gas-free message to establish a local trading session

The session can stay connected across visits if you opt in to **Stay Connected**.

## Troubleshooting

| Issue | What to try |
|---|---|
| Wallet not detected | Install the extension or open the site inside the wallet's in-app browser |
| Connection loop | Disconnect on pocket.fi, reset wallet connection, reconnect |
| Wrong network | Switch to the Pocket Chain testnet network shown in the wallet prompt |
| Enable Trading stuck | Refresh, ensure pop-up blockers are off, retry the signature |

## Security tips

- Never share your seed phrase or private key
- Verify the URL is `pocket.fi` before signing
- Disconnect when using a shared device

For passwordless access, see [Email login](/onboarding/email-login).
