Testnet V2 adds **email login** so users can trade without installing a browser wallet extension.

## How it works

Pocket integrates **Privy** for email authentication:

1. Click **Connect Wallet** → choose **Email**
2. Enter your email address
3. Enter the one-time passcode (OTP) sent to your inbox
4. Privy creates an **embedded wallet** tied to your email
5. Continue with **Enable Trading** as usual

## Embedded wallet behavior

| Topic | Behavior |
|---|---|
| Custody | Embedded wallet keys are managed by Privy; export options follow Privy policy |
| Same features | Spot, perps, portfolio, leaderboard—same as extension wallets |
| Onchain address | You receive a normal Pocket Chain address visible in Portfolio |

## When to use email vs extension wallet

| Use email if… | Use extension wallet if… |
|---|---|
| You want the fastest first-time setup | You already use MetaMask / OKX daily |
| You're on mobile without a wallet app | You need hardware wallet support |
| You're doing a quick testnet demo | You prefer full self-custody from day one |

## Troubleshooting

| Issue | What to try |
|---|---|
| OTP not received | Check spam; wait 60s; request a new code |
| Session expired | Log in again; re-run Enable Trading if prompted |
| Want to switch to MetaMask later | Connect MetaMask as a new address (accounts are separate) |

## Mainnet note

Email login availability on mainnet may differ based on compliance review. This page documents the **testnet V2** implementation.
