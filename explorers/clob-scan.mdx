**Clob Scan** is Pocket's in-app explorer focused on CLOB (central limit order book) activity on Pocket Chain testnet.

## What you can look up

| View | Description |
|---|---|
| Latest blocks | Recent block height, timestamp, tx count |
| Latest transactions | Recent trades, orders, and settlements |
| Block detail | All transactions in a block |
| Transaction detail | Decoded action type, status, participants |
| Address history | Trades and actions for a wallet address |

## How to open

- Top navigation → **Explorer** → Clob Scan
- Or search a tx hash from Portfolio / trade history

## Why use Clob Scan

Clob Scan is optimized for **trading-related** onchain events—fills, order updates, and clearing actions—so you can verify execution without leaving Pocket.

## Relationship to Pocket Scan

| Tool | Scope |
|---|---|
| **Clob Scan** | In-app; trading / CLOB events |
| **Pocket Scan** | Full L1 explorer |

Use both when you need trade-level detail (Clob Scan) and general chain activity (Pocket Scan).

## Testnet note

Clob Scan on testnet reflects **testnet chain data only**. Explorers reset or resync when testnet is redeployed.
